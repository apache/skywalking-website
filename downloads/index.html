Verify downloads

Use the PGP signature or SHA512 checksum provided with each release to verify your download. Download the Apache SkyWalking KEYS file to verify signatures.

PGP signature

gpg --import KEYS
gpg --verify apache-skywalking-apm-VERSION-src.tar.gz.asc apache-skywalking-apm-VERSION-src.tar.gz

SHA512 checksum

shasum -a 512 apache-skywalking-apm-VERSION-src.tar.gz

Compare the result with the downloaded .sha512 file.
